<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App lifecycle → local panel | Startup may construct only the local accessory window; no integration or external data path is allowed. |
| Pointer/keyboard → notch route | Native hit testing changes only local open/closed state and must not synthesize external input. |
| Static shell → user | The local state must never be presented as observed Desktop lifecycle data. |

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SwiftUI → launcher | A user gesture requests activation; no task identifier or user-supplied target crosses the boundary. |
| launcher → Launch Services | A fixed local bundle identifier crosses into macOS; success proves only OS acceptance/activation. |
| localized card → user | The fixed capability/explanation must remain complete across visual truncation and accessibility output. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-01 | Spoofing | Desktop card/header | high | mitigate | Fixed `Currently unobservable` model, no lifecycle field, one-card tests, and neutral collapsed symbol. |
| T-03-02 | Information disclosure | Credential/private-data paths | high | mitigate | No credential/store dependency and identifier-aware source gate; Plan 05 repeats phase-wide inventory. |
| T-03-03 | Denial of service | App activation | medium | mitigate | In-flight coalescing, five-second bound, explicit error, and retry tests. |
| T-03-04 | Elevation of privilege | Desktop action | high | mitigate | NSWorkspace only; no accessibility events, synthetic input, process injection, or guessed task link. |
| T-03-05 | Tampering | App target selection | medium | mitigate | Compile-time bundle constant, no interpolation, and exact-target tests. |

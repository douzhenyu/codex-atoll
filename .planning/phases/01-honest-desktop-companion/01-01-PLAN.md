**As a** Codex user, **I want to** open a truthful Desktop companion from the macOS notch, **so that** I can return to ChatGPT without being misled about task data Codex Atoll cannot observe.

Build the native walking-skeleton tracer: a renamed, attributable macOS app whose real SwiftUI → view model → launcher → NSWorkspace path shows one honest Desktop card and activates ChatGPT.

Purpose: Prove the inherited native shell and the phase's hardest safety boundary before adding secondary surfaces.
